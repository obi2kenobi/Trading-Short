# ponte-branch-usa-e-getta
**Àncora**: REPO-J (REPO-J) — sessione cloud senza filesystem condiviso ne
OAuth: unico canale col Mac dell'utente il repo GitHub. Ricetta: utente fa
clasp pull, git init, remote add, checkout -b live-snapshot-DATA, commit, push.
Sessione fa fetch e lavora da lì. Il branch resta come artefatto verificabile ·
**Nato**: 2026-08-28

Per leggere uno stato LIVE che la sessione non puo raggiungere da se (clasp
richiede login umano, nessun filesystem condiviso): il ponte e un BRANCH
USA-E-GETTA sul repo GitHub esistente. L'utente esegue clasp pull sul suo Mac,
pusha un branch live-snapshot-DATA; la sessione fa fetch e diff. Non un file
incollato in chat: un artefatto in history, verificabile, con autore e data.
